# JavaDSA — Legacy

Holds the original `Main.java` demo driver from before the repo was split into one branch per
data structure. Kept for reference; the per-structure branches (and `main`) are the current home
of the code. Part of [JavaDSA](https://github.com/A-Freeo/JavaDSA).

## Files

- `Main.java` — a labeled demo of the linked-list (and stack) methods.
- Supporting classes it needs to run: `Node`, `LinkedList`, `LinkedListController`, `Stack`,
  `StackController`, `Map`, `Entry`.

## Build & run

```
javac *.java
java Main
```
